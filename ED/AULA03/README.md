# Códigos de apoio — Aula 03

Cada pasta contém um programa independente, pronto para o JDoodle. Abra o compilador Java, copie o conteúdo do `Main.java` desejado e execute. Os exemplos que gravam arquivos criam a própria entrada e informam o nome do arquivo de saída; no JDoodle, consulte a área **Generated Files**.

1. `01-leitura-escrita`: cria, grava e lê um arquivo UTF-8.
2. `02-processamento-linha`: soma valores linha a linha.
3. `03-fatorial`: mostra caso base, validação e recursão.
4. `04-soma-vetor`: soma recursiva sem alterar o vetor.
5. `05-tad-pilha`: contrato de um TAD e uma implementação simples.
6. `06-loteria-jdoodle`: estudo de caso completo em um único arquivo.
7. `07-processador-notas`: prática completa, sem depender de arquivo enviado pelo aluno.

Execute uma pasta por vez. Todos os exemplos usam somente a biblioteca padrão e são compatíveis com Java 17 ou superior.
